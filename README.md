# VOX ROYALE

تأسيس تطبيق اجتماعي عربي للغرف الصوتية، بهوية بصرية أصلية داكنة بالبنفسجي والذهبي.

## الموجود في هذا المستودع حاليًا

- هيكل Flutter ابتدائي مع واجهة عربية RTL متجاوبة وتنقل محلي بين تبويبات التطبيق.
- حزمة أصول SVG أصلية كبداية للهوية المرئية (ليست نماذج 3D فعلية).
- ترحيل PostgreSQL تأسيسي لـ Supabase للملفات الشخصية والغرف والأعضاء والمقاعد، مع RLS وسياسات أولية.
- اختبار Widget أساسي.

هذه بداية تنفيذية وليست تطبيقًا تجاريًا مكتملًا: المصادقة الفعلية، خدمة RTC، المدفوعات، الإشعارات، لوحة الإدارة، والأصول ثلاثية الأبعاد الحقيقية لم تُنفّذ بعد. لا توجد بيانات حقيقية أو مفاتيح خدمات ضمن المستودع.

## التشغيل

يتطلب Flutter SDK مستقرًا حديثًا وDart المتوافق معه.

```bash
flutter pub get
flutter run
flutter test
```

## إعداد Supabase

1. أنشئ مشروع Supabase خاصًا بك.
2. شغّل ملفات `supabase/migrations/` بالترتيب عبر Supabase CLI أو SQL Editor.
3. مرّر عنوان المشروع والمفتاح العام (anon/publishable) وقت التشغيل، ولا تضع `service_role` أو أسرارًا في التطبيق:

```bash
flutter run --dart-define=SUPABASE_URL=https://YOUR_PROJECT.supabase.co --dart-define=SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_KEY
```

الاتصال بالخلفية غير موصول بعد في الواجهة الحالية. يجب إكمال سياسات الانضمام والمقاعد والعمليات الحساسة عبر RPC/Edge Functions قبل الإطلاق.

## الأصول

- `assets/brand/`: علامة SVG أصلية قابلة للتكبير.
- `assets/rooms/`: خلفية مشهد غرفة SVG مرسومة خصيصًا لهذا المشروع.
- `assets/gifts/`: رسم هدية SVG أولي.
- `assets/badges/`: شارة VIP SVG أولية.

هذه رسومات متجهية ثنائية الأبعاد بأسلوب حجمي؛ ليست ملفات GLB أو Blender ولا يجوز وصفها بأنها أصول 3D حقيقية. مجلد `assets/3d/` يحدد مواصفات إنتاج النماذج الفعلية وتحسينها للأجهزة.

## مراحل لاحقة

- ربط Supabase Auth وStorage وRealtime وEdge Functions.
- تكامل LiveKit أو Agora للصوت بعد توفير إعدادات المشروع ومفاتيح الخادم بطريقة آمنة.
- إكمال RLS واختبارات الصلاحيات قبل إضافة البيانات الحساسة والاقتصاد داخل التطبيق.
- إنتاج ملفات Blender/GLB أصلية وتصدير بدائل خفيفة للحركات.
- لوحة ويب إدارية، إشعارات FCM، الاختبارات الشاملة وبناء APK/Web.
