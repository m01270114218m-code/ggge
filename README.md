# VOX ROYALE

تطبيق Flutter عربي RTL بهوية أصلية داكنة بالبنفسجي والذهبي. هذا المستودع ما زال في مرحلة تأسيس الواجهة والتكاملات، ولا يُمثّل منصة جاهزة للإطلاق التجاري.

## التشغيل

```bash
flutter pub get
flutter run
flutter test
```

يتطلب Flutter SDK متوافقًا مع Dart 3.3 أو أحدث. لم تُشغّل أدوات البناء داخل بيئة GitHub هذه؛ شغّل الأوامر محليًا وتحقق من نتائجها قبل اعتبار البناء ناجحًا.

## الوظائف الموجودة في الواجهة الحالية

- استكشاف بصري للغرف مع تصنيفات وبطاقات قابلة للفتح.
- شاشة غرفة تجريبية: مقاعد محلية، إدخال رسائل محلي، تبديل حالة الميكروفون، وواجهة عرض هدايا.
- البحث والملف الشخصي وتبويبات الرسائل والإنشاء والترتيب.
- SVG أصلية أولية للعلامة والمشهد والهدية وشارة VIP.
- ترحيل Supabase تأسيسي في `supabase/migrations/`.

التفاعل في الغرفة محلي على الجهاز فقط: لا يوجد بث صوتي أو رسائل مشتركة أو شراء/خصم مالي. بيانات الغرف المعروضة عناصر تصميمية وليست بيانات مستخدمين أو خدمات حقيقية. الصفحات التي تعتمد على خدمات غير مهيأة توضّح ذلك للمستخدم.

## Supabase

أنشئ مشروع Supabase خاصًا بك ثم طبّق ملفات migrations بالترتيب. اتصال الواجهة غير مفعّل بعد. عند إضافته، استخدم عنوان المشروع والمفتاح العام فقط من إعدادات التشغيل؛ لا تضع `service_role` أو أسرارًا في التطبيق. العمليات الإدارية والمالية وحجز المقاعد يجب أن تكون عبر عمليات خادمية موثقة واختبارات RLS.

## حالة الأصول

- `assets/brand/`, `assets/rooms/`, `assets/gifts/`, `assets/badges/`: رسومات SVG أصلية ثنائية الأبعاد بأسلوب حجمي.
- `assets/3d/README.md`: موجز إنتاج.
- لا توجد في هذا المستودع صور فوتوغرافية، ملفات Blender `.blend`، نماذج `.glb`، ملفات Lottie/Rive، أو مكتبة أصول مكتملة. لا تصف رسومات SVG على أنها نماذج 3D.

## غير المنفذ بعد

مصادقة حقيقية وOTP، RTC عبر LiveKit/Agora، عضوية الغرف المتزامنة، إدارة المقاعد على الخادم، الدردشة الخاصة، الإشعارات، التخزين، الهدايا والمحفظة والمدفوعات، VIP، العائلات والوكالات، لوحة الإدارة، أنظمة المراجعة، اختبارات التكامل/الأمن، وتوليد APK/Web. يتطلب كل تكامل حسابات ومفاتيح وخدمات خارجية، كما يتطلب النشر إعدادًا واختبارات فعلية.
